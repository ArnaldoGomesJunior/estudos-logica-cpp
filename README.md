# Estudos de Lógica de Programação em C++

Este repositório contém exercícios e algoritmos práticos desenvolvidos de forma autônoma durante o 2º período da graduação em Engenharia de Software na UNAERP. 

O foco dos projetos é aplicar conceitos de modularização por funções, estruturas condicionais e laços de repetição (for, do-while) utilizando a linguagem C++.
